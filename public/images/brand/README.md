# Schattenschreck – Logos

Alle Logo-Dateien der Marke. Nicht von Hand bearbeiten: Sie werden mit
`python3 tools/brand/build.py` aus den Originalen in `tools/brand/quellen/` erzeugt.

| Datei | Inhalt | Wofür |
|---|---|---|
| `logo-quer.svg` / `.png` | Schriftzug „SchattenSchreck“ + „HORROR“, quer, transparent | Header, Intro, Unterseiten (Standard-Logo) |
| `logo-quadrat.svg` / `.png` | Schriftzug zweizeilig + „HORROR“, transparent | Social Media, quadratische Flächen |
| `signet-s.svg` / `.png` | Nur das rote „S“, transparent | Favicon-Basis, kleine Flächen |
| `signet-s-horror.svg` / `.png` | Rotes „S“ + „HORROR“, transparent | Profilbilder, Sticker |
| `*-dunkel.svg` / `*-dunkel.png` | Wie oben, auf dunklem Hintergrund (#0c0a0b) | Wo ein fertiges Bild mit Hintergrund gebraucht wird (Schema.org, Mails, Social) |

Farben: Rot `#96121c`, Weiß `#e6e6e6`, Hintergrund `#0c0a0b`.
Die weiße Zeile „HORROR“ ist nur auf dunklem Grund sichtbar – transparente Logos nie auf hellem Grund verwenden.
